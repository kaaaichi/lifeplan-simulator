# Claude Design 依頼プロンプト（ライフプラン・ダッシュボード）

以下をそのまま Claude Design に貼り付けて使う。

---

夫婦2人世帯向けの「ライフプラン・シミュレーション ダッシュボード」のUIをデザインしてください。日本語UIのWebアプリ（React + Recharts想定）で、PCとスマホの両対応（レスポンシブ）。

## このアプリの目的
現在の資産・収入・支出・将来のライフイベント（子の進学、住宅、退職など）を入力すると、老後（例:95歳）までの**資産推移を年次でシミュレーション**し、「老後までにいくら貯めるべきか／毎月いくら積み立てるべきか」を確認できるダッシュボード。日々の家計簿ではなく、長期の資産形成を俯瞰するツール。

## デザインのトーン
- 「将来のお金」を扱うので、**信頼感・落ち着き・誠実さ**。派手さより可読性。
- **数字とグラフが主役**。大きな金額・推移グラフが一目で頭に入る。
- 落ち着いた配色（ネイビー／ティール系＋十分な余白）。ダークモード対応だと尚良い。
- 金額は日本円（¥、万円表記の併用可）。

## 作ってほしい画面

### 1. ダッシュボード（メイン画面・最重要）
- ヘッダー: アプリ名ロゴ、現在のシナリオを切り替えるドロップダウン、ログインユーザーのアバター
- **KPIカード列**（PC=横並び5枚 / スマホ=縦積み）:
  1. 現在の総資産
  2. 終了年齢時点の総資産（黒字=緑/赤字=赤で強調）
  3. 資産が尽きる年（尽きなければ「生涯黒字」バッジ）
  4. 推奨される毎月の積立額
  5. コーストFIRE達成率（%＋進捗バー）
- **メイングラフ（画面の主役）**: 生涯資産推移の折れ線グラフ。
  - 総資産の中央線＋「運用が楽観/悲観だった場合」の幅を表す**塗りバンド**
  - X軸は西暦と年齢の2段ラベル（例: 2040 / 47歳）
  - 子の進学・卒業、退職、年金開始、住宅・家電の大型支出を**縦の注釈マーカー**で表示し、ホバーで内容ツールチップ
- **内訳ビュー**（メイングラフ下のタブ切替）:
  - タブA: 現金 vs 投資の積み上げ面グラフ
  - タブB: 単年度収支の棒グラフ（プラス=上/緑、マイナス=下/赤）
- **シナリオ比較トグル**: ONにすると複数シナリオの総資産線を1つのグラフに重ね、凡例と差分テーブルを表示

### 2. 入力画面
- アコーディオン or タブの6セクション: ①世帯メンバー ②資産 ③住居 ④生活スタイル ⑤家電買い替え ⑥前提条件
- ①世帯: 主生計者・配偶者・子（複数追加可）。各人に名前/生年月、年収、就労終了年齢。子には 小・中・高・大の学校種別セレクト（公立/私立/国立）、仕送り額、こづかい開始学年
- ②資産: 銀行口座を行で複数（ラベル＋残高）、投資残高も同様
- ⑥前提: 想定利回り(中央/楽観/悲観)、退職年齢、シミュレーション終了年齢、年間投資額をスライダー/数値入力
- 入力中、**PCでは右ペイン・スマホでは下部に資産推移グラフのライブプレビュー**

### 3. シナリオ管理画面
- シナリオをカード一覧で表示。各カードに 名前、要約（終了時総資産・推奨積立額）、複製/編集/削除、「比較に含める」チェックボックス
- 「現プランを複製」ボタン（学校種別や退職年齢だけ変えた別案を作る用途）

### 4. ログイン画面
- 中央に「Googleでログイン」ボタンのみのミニマルな画面。許可外アカウント時は「アクセス権がありません」を控えめに表示

## 補足
- 主要ユーザーは2人（夫婦）。スマホでサッと見る場面と、PCでじっくり入力・比較する場面の両方がある
- グラフは Recharts で実装予定なので、Recharts で表現可能な範囲（折れ線/面/棒/参照線/バンド）で構成してほしい
- まずは**ダッシュボード画面を最優先**でデザインしてください。
